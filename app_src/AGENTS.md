# 星河GEO 后台

## 项目概览

星河GEO（本地商户 SEO/关键词优化）客户交付后台，用于管理线索、客户合同、月报、关键词检测等业务。核心目标：自建账号体系 + httpOnly Cookie 会话，登录绝对稳定。

## 技术架构

### 认证体系（自建账号）
- 账号密码登录，密码 bcrypt 哈希存储
- 会话通过 httpOnly Cookie 存储 `geo_session_id`（UUID）
- 服务端 `geo_sessions` 表维护会话状态，含过期时间（24h 不活动过期，7天最大有效期）
- 401 区分：无会话 vs 会话过期，响应头 `X-Session-Expired: true` 标记过期
- 不依赖 localStorage token，不依赖平台账号体系
- 匿名访问直接进入应用自己的登录页 `/login`

### 角色体系（自建业务角色）
- `admin`：全功能
- `operator`：内容/关键词/发布，不能改账号与套餐
- `client`：只读自己品牌数据

角色在用户表用 `role` 字段标记，服务端中间件校验，前端路由守卫控制。

### 数据模型

核心表：
1. `geo_users` - 用户表（用户名、密码哈希、角色、绑定品牌）
2. `geo_sessions` - 会话表（session_id、user_id、过期时间）
3. `geo_brands` - 品牌/客户表
4. `geo_leads` - 线索池
5. `geo_lead_followups` - 线索跟进记录
6. `geo_contracts` - 客户合同
7. `geo_payments` - 分批收款记录
8. `geo_monthly_reports` - 月报
9. `geo_keywords` - 关键词词库
10. `geo_keyword_tasks` - 检测任务
11. `geo_keyword_results` - 检测结果
12. `geo_auto_tokens` - 自动化接口令牌

## 内容生产模块

### 菜单结构
「内容生产」一级菜单，含 4 个二级页：
1. AI 文章（创作 + 列表）
2. AI 图片（生成 + 历史列表）
3. AI 视频（任务列表 + 外部服务配置）
4. 素材库（图片/视频/文档三 tab）

### 统一交互
- 左侧表单 / 右侧生成结果预览 / 下方历史记录
- <768px 上下堆叠
- 客户角色只能看自己品牌数据，品牌下拉锁定
- admin/operator 可切换品牌
- 算力扣减写流水，余额不足禁止发起

### AI 文章
- 品牌 → 核心关键词（从关键词库带出，多选）→ 长尾关键词（输入添加，可批量粘贴）→ 创作类型（排行推荐/评测对比/创意故事/科普解读/问答答疑）→ 配图（从素材库选）→ 生成篇数（1-10）→ 参考知识库（可勾选）
- 真实调用 AI 生文插件（geo_text_generate_1），流式展示进度
- 生成后：标题、正文（富文本）、字数、消耗算力；可编辑、复制、保存、删除
- 失败显示具体原因，不写假文章
- 列表：标题、品牌、类型、字数、状态（草稿/已发布）、创建时间；支持筛选和搜索

### AI 图片
- 品牌 → 画面描述（提示词）→ 风格（写实摄影/插画/极简电商风/国潮等）→ 尺寸（1:1/4:5/3:4/16:9/9:16）→ 数量（1-4）
- 优先用平台内置生图插件（geo_image_generate_1）
- 无可用能力时：提供「生图服务配置」入口（API 地址、Key、模型），可测试连通性；未配置时页面明确提示，不返回假图
- 生成结果进素材库，可下载、删除、作为文章配图
- 每张扣固定算力

### AI 视频
- 任务页：品牌 → 视频主题/脚本要点 → 时长（15s/30s/60s）→ 比例（9:16/16:9/1:1）→ 首帧图（从素材库选）→ 提交生成
- 外部服务配置：API 地址、Key、模型、回调地址
- 提交 + 轮询流程：提交任务 → 按任务号轮询状态 → 成功后存视频地址与封面
- 未配置时页面明确显示「未配置视频生成服务」，不生成假视频
- 任务列表：任务名、品牌、时长、比例、状态（排队/生成中/已完成/失败）、创建时间；已完成可播放、下载

### 素材库
- 三个 tab：图片 / 视频 / 文档
- 上传（多选）、按品牌分组、新建分组、批量删除、重命名
- 总容量与已用容量
- 生成的图片/视频自动归档到对应品牌分组

### 首页内容产出统计
- 本周文章 / 图片 / 视频数量
- 本周算力消耗

## GEO 闭环模块

### 四步工作流
同一页 `/geo-loop` 内四段 + 顶部四步进度条：
1. 内容生产（已实现）
2. 分发节奏（占位卡，即将上线）
3. 收录引导（占位卡，即将上线）
4. 效果闭环（已实现）

### 第一步·内容生产
- **品牌定位档案**：geo_brand_profiles 表，6 个字段（定位一句话/行业/目标受众/卖点/禁用表述/主打问题），完整度进度
- **内容矩阵**：geo_content_pillars 表，支柱 → 子话题树状，按矩阵批量生成创作任务
- **内容结构检查**：geo_content_checks 表，7 项加权打分（标题/首段/标题层级/FAQ/数据引用/内链/字数），批量重新检查

### 第四步·效果闭环
- **竞对差距**：geo_content_gaps 表，关键词对比，批量转成创作任务
- **优化建议清单**：geo_action_items 表，规则自动生成（结构低分/矩阵空白/差距高优/发布低频），一键采纳，状态切换

### 新表（5 张）
1. geo_brand_profiles — 品牌定位档案
2. geo_content_pillars — 内容矩阵
3. geo_content_checks — 内容结构检查
4. geo_content_gaps — 竞对差距
5. geo_action_items — 优化建议清单

## 设计规范

### 色彩体系
- 主色（品牌蓝紫）：`#3B5BFF` — 主操作、选中、链接
- 强调色（青）：`#00C2FF` — 关键数字、图表主线、状态灯、首页重点标记
- 成功色：`#17C964`
- 警示色：`#FFA940`
- 危险色：`#FF5C5C`
- 中性：文字 `#0f172a`、辅助 `#64748b`、描边 `#E5E9F2`、表头 `#F7F9FC`

### 首页深色科技风（仅数据总览页）
- 底色：`#0A0E1A`（近黑蓝）+ 极淡网格线（rgba(255,255,255,0.03)，32px 间距）
- 面板：`#111827`，次级面板 `#161E2E`
- 描边：`1px solid rgba(46,125,255,0.18)`
- 卡片圆角：`12px`
- 阴影：冷光感 `0 0 0 1px rgba(46,125,255,0.06)`，无大面积黑色阴影
- 布局：顶部状态条 56px + KPI 区（4大卡 + 4小卡）+ 中部图表（60%折线+40%环形/条形）+ 底部三等分区块
- 标记：重点 KPI 卡左上角 2px 青色短标记（限 2-3 张）
- 禁止：紫色渐变、毛玻璃、彩虹霓虹、每张卡片发光

### 浅色页面（业务页通用）
- 页面背景：`#f8fafc`
- 卡片：白色 `#ffffff`，描边 `#E5E9F2`，圆角 `12px`
- 表格：表头底色 `#F7F9FC`，行高 `44px`，数字列右对齐 + 等宽数字
- 按钮：主按钮 `#2E7DFF` 实心，次按钮白底 + `#E5E9F2` 描边，危险操作 `#FF5C5C` 文字按钮
- 页面标题区：标题 20px/600 + 一行灰色说明文字

### 侧边栏（浅色）
- 背景：`#fafbfc`
- 选中态：左侧 2px 蓝色竖条 + 文字 `#2E7DFF` 字重 600 + 背景 `rgba(46,125,255,0.06)`
- 分组标题：`#94a3b8` 灰色 uppercase 小字

### 字体
- 中文：Noto Sans SC / 思源黑体
- 数字：`font-variant-numeric: tabular-nums`（.tnum 类）
- KPI 大数字：40-48px，字重 700
- 标题：600 字重

### 动效（克制，仅 3 处）
1. 首页 KPI 数字首次加载 count-up（600ms，只跑一次）
2. 折线图首次加载从左到右扫入（800ms）
3. 卡片 hover 描边变亮，无位移和放大
其余一律不动效。

## 页面路由

- `/login` - 登录页（无布局）
- `/` - 首页看板
- `/geo-loop` - GEO 闭环（四步工作流）
- `/leads` - 线索池
- `/contracts` - 客户合同
- `/reports` - 月报
- `/keywords` - 关键词管理
- `/settings` - 设置（令牌管理、改密码）

## OpenAPI

- `GET /api/automation/keywords/pull?limit=N` - 拉取待检测关键词
- `POST /api/automation/keywords/result` - 回传检测结果
- 鉴权：`X-Auto-Token` 请求头
- 路由从 CSRF 保护中排除，外部服务可直接调用
